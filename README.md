# MI Prison

En dansk landing page-prototype til MI Prison Minecraft-serveren.

## Kør lokalt

Åbn `index.html` direkte i browseren, eller start en lokal statisk server:

```bash
python -m http.server 8080
```

Besøg derefter <http://localhost:8080>.

Login, roller, ansøgninger og webshop er i denne version en frontend-prototype.
Før offentlig lancering skal login kobles til en sikker backend, database og
betalingsløsning. Adgangskoder må aldrig gemmes i frontend-koden.
